# Option 3 recovery fixtures

`option-3-v1.json` is the immutable A0 recovery snapshot of the original rectangle-based editor state. Values remain in the legacy millimetre coordinate space exactly as they existed before ProjectV2.

The preserved tracing image remains at `dist/assets/option-3-reference.png`. Its frozen SHA-256 digest is:

`56dbc61d59013c5f5247af5f684059097bb233da960379551b78c58f7ef01a37`

Neither recovery artifact is a topology model. `option-3-topology-v2.json` is
the deterministic A2.3 canonical wall graph generated by the purpose-built
`createOption3TopologyV2()` insertion sequence. It is authoritative for physical
wall centre-lines only; the V1 rectangles and image remain independent recovery
and visual-reference sources.

`option-3-semantic-spaces-v1.json` is the deterministic A3.2 golden fixture for
the 13 explicit persistent SpaceId-to-FaceId bindings. It contains no face
polygon or area; those remain derived from canonical topology.
