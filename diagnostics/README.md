# Development diagnostics

`option-3-topology-overlay.svg` overlays the A2.3 canonical wall bands,
centre-lines, and nodes on the preserved Option-3 reference. It is generated by
`npm run diagnostic:topology-overlay` and is not loaded by the production UI.

`option-3-semantic-spaces-overlay.svg` overlays all 13 A3.2 semantic names,
stable SpaceIds, derived FaceIds, and face areas on that same fixed reference.
It is generated together with the mapping report by
`npm run diagnostic:semantic-spaces` and is also dev-only. A second generated
copy under `dist/diagnostics/` makes the same diagnostic available from the
normal local `dist/` preview server.
